# ADOPET

Sistem Layanan Adopsi & Perawatan Hewan Peliharaan berbasis web menggunakan Laravel.

## Teknologi

- Laravel
- PHP
- SQLite
- Blade
- Tailwind CSS

## Instalasi

1. Clone repository:

   ```bash
   git clone https://github.com/wima09/ADOPET.git
   ```

2. Masuk ke folder project:

   ```bash
   cd ADOPET
   ```

3. Instal dependency:

   ```bash
   composer install
   ```

4. Salin file konfigurasi:

   ```bash
   cp .env.example .env
   ```

5. Generate application key:

   ```bash
   php artisan key:generate
   ```

6. Jalankan migration:

   ```bash
   php artisan migrate
   ```

7. Jalankan aplikasi:

   ```bash
   php artisan serve
   ```
